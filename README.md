# CẢNH GIÁC ONLINE - STUDENT VERSION v1.1

Phiên bản chính thức dành cho học sinh THCS sử dụng ngay trên điện thoại.

## Điểm mới

- Không cần đăng nhập.
- Không cần mã học sinh do giáo viên cấp.
- Khi mở app, hệ thống tự tạo một mã phiên ẩn danh để lưu tiến bộ.
- Không yêu cầu họ tên, email hay số điện thoại.

## Chức năng

- Kiểm tra thông điệp đáng ngờ.
- Giải thích dấu hiệu cảnh báo và khuyến nghị xử lý.
- Thử thách tình huống an toàn số theo chủ đề.
- Theo dõi tiến bộ của phiên học ẩn danh.
- Góc kiến thức an toàn số.

## Quyền riêng tư

- Không nhập OTP thật, mật khẩu, số thẻ, số tài khoản hoặc thông tin bí mật.
- Ứng dụng không lưu nội dung tin nhắn người dùng nhập để kiểm tra.
- Chỉ lưu kết quả phân tích và kết quả luyện tập gắn với mã phiên ẩn danh tự động.

## Chạy thử trên máy tính

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```
